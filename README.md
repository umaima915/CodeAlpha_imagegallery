# 📸 Image Gallery

A responsive image gallery built with HTML, CSS, and JavaScript.

## ✨ Features

- 🎨 **Category Filters** - Nature, Urban, Portrait, Abstract
- 🖼️ **Lightbox View** - Full-screen image preview
- 🔄 **Navigation Buttons** - Previous/Next with counter
- 🎯 **Active Image Border** - Visual indicator while navigating
- ✨ **Hover Effects** - Smooth zoom & overlay animations
- 📱 **Responsive Design** - Works on all devices
- ⌨️ **Keyboard Navigation** - Arrow keys support
